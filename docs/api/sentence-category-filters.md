# 문장 연습 카테고리 — V58 연동

`GET /api/practice-contents/facets?type=SENTENCE`의 `categories[].label`을 화면에 표시하고
`categories[].value`를 선택 상태와 목록 요청에 그대로 사용한다.
문장 화면의 선택지는 다음 네 코드 중 실제 facets 응답에 포함된 항목으로 제한한다.

| 표시명 | 요청값            | V58 추가 문장 수 |
| ------ | ----------------- | ---------------: |
| 받침   | `FINAL_CONSONANT` |                5 |
| 된소리 | `TENSE_CONSONANT` |                0 |
| 자음   | `CONSONANT`       |                5 |
| 모음   | `VOWEL`           |                5 |

- `tense` 고정 변환과 한글 표시명을 요청값으로 사용하는 fallback을 제거했다.
- facets 조회 전에는 필터 버튼과 필터별 요청을 보류한다. 조회 실패·빈 선택지는 재시도를 제공한다.
- 누락된 코드는 생성하지 않는다. 전체 목록 조회는 facets와 독립적으로 진행하며 `category`를 생략한다.
- 첫 페이지와 더 보기는 같은 검증된 값을 사용한다. 필터 변경 시 과거의 캐시 페이지 수를 복구하지 않고 0페이지로 시작한다.
- 뒤로가기로 같은 목록에 돌아오는 경우에는 기존 페이지 범위 복구를 유지한다.
- 이전 한글·소문자 카테고리로 만든 필터 상태와 캐시는 새 `SENTENCE-facets-v2` 범위에서 재사용하지 않는다.

검증: 실제 필터 이벤트·렌더링, facets 실패/재시도, 요청 보류, 캐시가 있는 필터 변경,
전체/더 보기/다음/이전 요청의 코드 보존을 회귀 테스트한다.
V58 PostgreSQL 테스트는 신규 15개 문장, 네 코드의 한글 표시명, 기존 전체 콘텐츠 보존과 재실행 시 중복 방지를 검증한다.

추가 문장 수는 운영 목록의 총 개수가 아니다. 된소리 기존 문장을 포함한 운영 계정별 실제 개수는 로그인된 목록 응답으로 확인해야 한다.
