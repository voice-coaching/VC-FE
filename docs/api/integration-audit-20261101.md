## API

컨트롤러의 공개 경로와 DTO를 기존 어댑터에 대조했다. 최근 추가된 아래 API는 이미 기본 연결되어 있었으며, 누락된 세션 쿼리와 화면 동작을 보완했다.

| API                                                  | 적용 및 확인                                                                                   |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `GET /api/courses/{courseId}/practice-examples`      | 순차 클래스 진입. 기존 세션 재진입 시 `sessionId`를 전달해 예문 revision 보존                  |
| `GET /api/users/me`                                  | `free` / `paid` / `admin`, 만료일을 MyPage 이용권 카드와 관리 화면에 반영. 캐시 표시 후 재조회 |
| `POST /api/payment-orders`                           | `Idempotency-Key` 유지. 기존 주문의 완료·실패·취소 상태에서는 결제창 재호출 방지               |
| `GET /api/payment-orders/{orderId}`                  | 결제 상세 직접 진입 및 최신 상태 조회                                                          |
| `POST /api/payment-orders/{orderId}/verify`          | 서버 검증 후 완료·대기·실패·취소를 구분하고 내역 갱신                                          |
| `GET /api/users/me/payment-orders`                   | 월별 내역과 페이지 추가 조회. 로그인 세션별 요청 병합                                          |
| `POST /api/payment-orders/{orderId}/cancel`          | 전액 취소, 서버 사유 검증 규칙 반영                                                            |
| `POST /api/payment-orders/{orderId}/refund-requests` | 전액 환불 신청 및 상태 화면 연결                                                               |
| `GET /api/refund-requests/{requestId}`               | 저장된 요청의 UNKNOWN / PENDING / SUCCEEDED / FAILED 상태 재확인                               |
| `GET /api/users/me/weakness-recommendations`         | MyPage 약점 연습 버튼을 추천 문장에 연결. 추천이 비어 있으면 발음 클래스 진입                  |

결제 한도 초과는 `Retry-After`를 따라 한 번 재시도하며, 503은 자동 재요청하지 않는다. 이용권 기간은 백엔드 `PaymentOrder`의 UTC 달력 기준 **1개월**이며 30일로 계산하지 않는다. 유효한 결제 이용권의 추가 구매는 제한한다.

분석은 공개 canonical v3 계약을 사용한다. 검증 스크립트에서 폐기된 결과·세그먼트·피드백 재생성 경로 기대값을 제거하고, 실제 v3 projection과 서버 action을 검증하도록 수정했다. 서버 내부 AI 수신 API와 PortOne 웹훅은 브라우저에서 호출하지 않는다.

### 백엔드 계약에 맞춘 차이

Figma의 무료 8회/유료 30회 잔량, 사용량 과금, 자동결제/해지, 사용량별 부분 환불은 현재 VC-BE에 대응 데이터/API가 없다. 이 값과 동작을 가정하지 않고 실제 이용등급·만료일·비갱신 TEST 결제·전액 취소/환불로 표시한다. 따라서 횟수 소진 시트와 자동결제 해지 화면은 연결하지 않았다. 백엔드 제공 이후 해당 디자인을 연결할 수 있다.
