# 항목별 발음 점수 표시

분석 상세 API의 data.scoreBreakdown을 그대로 표시한다. 기대 음소 표본이 없는 항목(applicable=false, score=null)은 평가 대상 없음이며 0점으로 바꾸지 않는다. 필드 자체가 없거나 null인 과거 결과는 항목별 정보 없음으로 표시한다.

항목 점수는 기본 배점 기준(score / maxScore)이며 소수 둘째 자리까지 보존한다. 종합 점수는 applicableMaxScore를 분모로100점 환산한 백엔드 overallScore를 사용한다. 프론트가 점수를 재채점하지 않는다.

항목 이름을 클릭·터치하면 설명을 열고 다시 누르면 닫는다. 마우스를 올리거나 키보드로 포커스해도 설명을 볼 수 있다. Escape로 닫을 수 있다. 설명 문구와 기대 표지는 API의 description/expectedPhones를 사용한다.

신규 API는 9개 항목을 반환한다: 모음25, 평음 파열음10, 경음 파열음10, 격음 파열음10, 마찰음10, 파찰음10, 비음10, 유음5, 기대 음소 대응 범위10.
배포 순서가 달라도 기존 서버의 응답에는 scoreBreakdown이 선택 필드이므로 오류가 발생하지 않는다. 백엔드 배포 전에는 실제 항목별 점수가 표시되지 않는다.
