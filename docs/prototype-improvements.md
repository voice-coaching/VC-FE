# 프로토타입 개선 진행표

2026-09-11 사용자 제공 리뷰와 현재 코드를 대조한 작업 기록입니다.
체크되지 않은 항목은 아직 완료한 것으로 보지 않습니다.

## 이미 반영된 항목

- [x] 홈 오늘의 연습 → 특정 뉴스의 3문장 준비 화면 (`/news/today`).
- [x] 내 문장 전송·분석 → 입력 원고 기반 결과 화면.

## 단계별 남은 개선

### 1. 결과에서 한 문장 집중 연습

- [x] 내 문장 결과에서 선택한 문장만 예시 → 녹음 → 확인 → 전체 결과로 복귀.
- [x] 기존 전체 녹음·결과를 초기화하지 않고 별도의 녹음 상태 사용.
- [x] 재연습 완료 문장 표시, 이번 녹음 이탈·재녹음 확인.
- [x] 뉴스·아나운서 결과에도 집중 연습 연결. 진입 시 기존 재생 정지, 취소·완료 후 선택한 문장으로 스크롤·키보드 초점 복귀.
- [x] 뉴스(정보 전달·호흡)와 아나운서(속도·억양 따라 읽기)의 집중 연습 안내 구분.
- [ ] 이전 시도와 재시도를 비교하는 화면. 실제 분석 없이 향상 점수를 임의 생성하지 않기.

### 2. 작업 손실 방지

- [x] 기존 뉴스·내 문장·아나운서 화면 내 뒤로 가기·재녹음·결과의 다시 읽기 확인 통일. 녹음 중이거나 녹음 완료 상태일 때만 확인하며, 취소는 recorder를 초기화하지 않음.
- [x] 녹음이 있을 때 새로고침·탭 닫기 `beforeunload` 기본 경고 요청. 표시 여부는 브라우저 정책에 따름.
- [ ] 브라우저 자체 뒤로 가기 / 모바일 뒤로 가기 제스처 보호 및 실기기 검증. `beforeunload`는 SPA 내부 이력을 보호하지 않음.
- [x] 원고 sessionStorage 임시 저장, 재진입 복구 선택, 삭제 확인. 서버 전송 없음·탭 단위 보관·탭 복원 시 남을 수 있음 안내. 저장 실패 별도 안내.
- [x] 300자 제한 사전 안내. 초과 원고를 자르지 않고 보존, 초과 글자 수 안내·다음 단계 비활성화. 공백·줄바꿈 포함, 이모지·조합 문자 단위 계산.

### 3. 준비 화면과 버튼 역할

- [x] 원고 확인에 원고 수정 버튼. 원고·임시 저장 유지, 입력칸 초점 복귀, 수정한 원고로 문장 재분할.
- [x] 예시 듣기 → 녹음 화면으로, 녹음 대기 → 마이크 안내로 문구 정리. 뉴스·내 문장·문장 연습·아나운서·클래스 공통 문구 사용. 실제 녹음 버튼의 접근성 이름은 녹음 시작 / 녹음 마치기.
- [x] 뉴스 준비에서 핵심 요약·표현 다듬기와 원문 문장 분할을 구분해 안내. 오늘의 연습 문장 수도 실제 선택된 문장 수로 표시.

### 4. 완료와 누적 성과

- [x] 프로토타입 완료 기록 저장, 홈 오늘 문장 수·최근 기록·오늘의 3문장 완료 상태 연결. 개발 전용 `/home/history`에서 확인·삭제.
  - 뉴스·문장·따라 읽기·내 문장은 결과의 연습 마치기, 클래스는 단계 완료 시 기록. 도중 취소는 기록하지 않음.
  - 최근 100개를 localStorage에 보관. 실제 계정 기록과 분리하며, 원고·음성·분석 점수는 저장하지 않음. 중복 완료 방지, 저장 실패 안내 포함.
  - 집중 재연습의 개별 시도 비교·누적은 별도 남은 항목.
- [ ] 점수와 비율의 지표 정의. 정의 없이 종합 점수로 이름만 바꾸지 않기.
- [ ] 기사별 결과 일관성, 모드별 피드백 목적 정리.
  - [x] 뉴스 발음 상세의 공통 오류 6개·고정 음절 집계 제거. 선택한 기사에서 숫자와 표현을 추출하고 실제 문장 번호로 표시. 오류 판정이 아닌 연습 제안임을 명시.
  - [x] 다른 기사에도 나오던 ‘삼점오퍼센토’와 특정 표현의 고정 오류 강조 제거.
  - [ ] 종합 카드·문장 점수·속도·억양 수치는 아직 공통 예시 데이터. 실제 분석 지표 및 기사별 결과 설계는 별도 남음.

### 5. 모바일과 예외 상황

- [x] 모바일 전체 화면 / PC 기기 프레임 분리. 767px 이하 및 터치 기기 1023px 이하에서 축소·테두리 제거, 데스크톱 402×874 미리보기 유지.
  - 실제 안전 여백 적용, 가상 44px 상태 표시 여백 제거. VisualViewport 기반 키보드 높이 변화 대응, 16px 이상 입력 글자, 사용자 핀치 확대 유지.
- [ ] 키보드·터치 크기 실기기 검증.
- [ ] 실서비스 전 권한·무음·업로드 실패·분석 실패 복구 화면.
