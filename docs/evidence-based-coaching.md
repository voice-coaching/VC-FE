# 발음 코칭 화면

`feat/evidence-based-coaching`, 2026-09-18. 운영 미배포.

`GET /api/analyses/{id}`의 `coaching.schemaVersion=voice-coaching.coaching-result.v1`이면 요약 → 우선 연습 → 자기 확인 → 근거 펼치기를 표시한다. null/구버전/지원하지 않는 버전은 기존 AnalysisView를 유지한다.

- 유효한 CTC 구간과 기존 녹음 URL이 있을 때만 해당 위치부터 다시 듣기를 제공한다. 실제 발음 경계를 확정한 것으로 표시하지 않는다.
- LIMITED_EVIDENCE를 음질 실패로 치환하지 않는다. 보류 점수는 0점이 아니다.
- LLM 실패 후 TEMPLATE이면 기본 연습 안내임을 표시한다.
- 입술 수치는 의미를 풀어 쓴 이름과 구간으로 표시한다. 미검증 기준에서 좋음/나쁨 색상이나 개인 입 벌림 교정을 만들지 않는다.
- 원래의 다음 녹음·실패 재시도·상태 재조회 흐름은 유지한다. 새 학습 비교가 없으면 개선을 추정하지 않는다.

Backend v3 reader/문서 저장을 먼저 반영해야 한다. 변경이 없는 예전 분석에서 코칭 데이터를 합성하지 않는다. 실제 녹음·브라우저 품질 QA와 운영 배포는 별도 확인 대상이다.
