# 완료 학습 기록 표시

`/mypage/history`는 `/api/users/me/training-sessions?status=COMPLETED&page=…&size=20`의 완료 목록을 기준으로 표시한다. 목록 진입 시 각 세션 상세 및 canonical 분석 결과를 선조회하지 않으며, 코칭 교정 항목·피드백 유무로 완료 기록을 숨기지 않는다. 기존 상세 화면을 열면 세션·분석 결과를 조회하고 실패 안내·재시도를 제공한다. 목록의 페이지 이동·사용자별 캐시·스크롤 복원을 유지한다.

현재 목록 DTO에는 origin/category가 없으므로 문장 콘텐츠의 내 문장 분류와 승급시험 제외에 필요한 콘텐츠 메타데이터 조회는 유지한다. 동일 콘텐츠는 한 번만 조회하고 사용자별 기존 콘텐츠 캐시를 재사용한다. 확인된 승급시험은 제외하며, 확인하지 못한 콘텐츠는 전체 목록에서 숨기지 않고 분류 오류·재시도를 안내한다. 내 문장 탭은 USER_INPUT으로 확인된 기록만 표시하며 분류 실패도 재시도할 수 있다. 따라서 모든 숫자형 상세 요청이 사라지는 것은 아니며, 세션·분석 선조회와 콘텐츠 중복 요청이 제거된다.

직접 분석 목록은 기존 `/api/direct-analysis-history`를 사용한다. ACCEPT이고 failure가 없는 결과의 `coaching.feedback` 문구 또는 `coaching.items[].expression.action`을 지원한다. 피드백이 없는 실패 결과는 기존처럼 리포트 목록에 표시하지 않는다. AI 계약·스키마·점수 계산은 변경하지 않는다.

리포트 저장 선택은 기존 사용자별 localStorage 북마크다. 이번 변경은 서버 저장/학습 완료/승급 명령을 추가하거나 재전송하지 않는다. 전체 기록 조회와 저장 북마크는 별개이며, 다른 기기로 북마크를 동기화하지 않는다.

검증: 목록/분류/피드백 표시와 기존 페이지·캐시·canonical 저장/완료/전송 자동 테스트 27개 통과. 로컬 API 대역 브라우저에서 8건 목록·분류 실패 및 재시도·빈 목록·직접 분석 두 형식/실패 제외·상세 오류 후 재시도·페이지 추가 6개 시나리오 통과. 같은 콘텐츠의 메타데이터는 1회, 목록 진입 시 세션/분석 상세 요청은 0회다. 프로덕션 빌드와 변경 코드 ESLint도 통과했다. 운영 사용자 원본 데이터로 검증한 것은 아니다.
