# 승급 시험 녹음 진입 수정 — 2026-11-01

## 문제

승급 시험에 `trainingSessionId`가 연결돼 있으면 녹음 전인 세션도 즉시 분석 대기 화면으로 전환했다. 선택된 녹음이 없으면 분석 복원에 실패하고, 다시 확인해도 녹음을 시작하기 어려웠다. 시험에서 나간 뒤에는 취소된 세션 ID를 재사용하는 경로도 있었다.

## 변경

- 세션 복원 중에는 ‘승급 시험을 준비하고 있어요’를 표시한다.
- `RECORDING`·`UPLOADING` 상태이며 완료된 분석이 없는 세션은 녹음 준비 화면으로 연다. 이미 업로드한 녹음이 있어도 분석 제출 전이면 새로 녹음할 수 있다.
- 실제 분석 중이거나 결과가 있는 세션은 선택된 녹음 ID로 기존 분석을 복원한다.
- 취소·실패한 시험 세션은 화면에서 분리한다. 이후 분석 요청에 필요한 세션은 시험 ID와 함께 서버에 요청하여 원자적으로 재사용하거나 새로 연결한다.
- 세션 조회 실패 시 ‘학습 상태 다시 확인’으로 조회를 재시도한다. 조회가 끝나기 전에는 세션을 자동 취소하지 않는다.

## 검증

- 승급 시험·세션 복원·분석 완료·예문·오류 처리·이력 탐색 관련 회귀 테스트 44개 통과.
- `npm run verify:api`: 88개 요청 계약과 인증 갱신 검증 통과.
- `npm run build`: TypeScript와 프로덕션 빌드 통과.
- 변경 파일 ESLint 오류 없음. 기존 `loadResult` effect 의존성 경고 1개는 남아 있다.
- 브라우저의 실제 마이크 녹음 및 배포 환경 채점은 수행하지 않았다.
