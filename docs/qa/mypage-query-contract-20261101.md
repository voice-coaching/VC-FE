# 마이페이지 통계 요청 오류 수정 — 2026-11-01

## 원인과 변경

마이페이지 누적 통계와 성장 그래프에서 `period=ALL`을 전송해 `400 INVALID_INPUT_VALUE`가 발생했다. VC-BE의 `MyPagePeriod`는 `WEEK`, `MONTH`, `THREE_MONTHS`, `YEAR`만 지원한다.

- 누적 통계는 사용자 가입 날짜를 서울 시간대의 날짜로 변환해 `from`으로 전달한다. 종료 날짜는 백엔드의 오늘 날짜를 사용한다.
- 성장 그래프는 `period=YEAR`를 조회한다. ‘전체’ 선택지는 ‘연간 · 최근 1년’으로 표시하고, 주간 8주와 월간 6개월 집계는 유지한다. 현재 점수 추이 API로 가입 이후 전체 기간을 조회한다고 표시하지 않는다.
- 마이페이지 기간과 점수 지표 타입을 백엔드 허용 값으로 제한했다.
- 만료되었거나 만료가 10초 이내인 JWT는 보호된 API 요청 전에 갱신한다. 동시 클래스 요청이 같은 갱신을 공유하고, 새 토큰이 거부되어도 추가 갱신 루프를 만들지 않는다. JWT 만료 정보는 갱신 시점 판단에만 사용하며 인증은 서버에서 수행한다.

스크린샷의 클래스 `401`이 최종 인증 실패인지, 기존 자동 갱신 이전 요청의 응답인지는 스크린샷만으로 확정할 수 없다. 사전 갱신은 만료 토큰으로 발생하는 초기 실패를 줄인다. 갱신 세션 자체가 만료된 경우에는 기존 로그인 실패 처리를 유지한다.

## 검증

- 관련 회귀 테스트 47개 통과: 마이페이지 날짜·기간, 동시 인증 갱신, 로그인 전환, 음성 재생·업로드, 네이티브 콜백.
- API 계약 검증 88개 통과. 명시적 통계 시작 날짜와 연간 점수 추이 요청을 추가했다.
- 변경 파일 ESLint 오류 없음.
- 프로덕션 빌드 및 TypeScript 검증 통과.

개발용 자동 생성 파일 `.next/dev/types/validator.ts`에 손상된 중복 내용이 있어 진단용으로 보관한 뒤 빌드했다. 해당 임시 파일은 커밋에 포함하지 않는다.
