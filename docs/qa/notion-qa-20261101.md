# Notion QA 점검 및 수정 — 2026-11-01

대상: [QA 페이지](https://app.notion.com/p/QA-3ecfd927f58c8030a76bc63a7812f81a).
전체 보기와 하위 페이지를 포함해 내용이 있는 이슈 31개를 확인했다. 제목과 내용이 없는 행 2개는 제외했다.

## 이번 변경

- 기록 및 리포트 조회에서 현재 VC-BE에 없는 `/api/users/me/report-saves` 호출을 제거했다. 저장 선택은 계정별 기기 내 목록으로 보관하며, 저장 창과 저장 화면에 범위를 안내한다. 저장소 접근 실패가 일반 기록 조회까지 차단하지 않도록 처리했다.
- 등록된 가이드 음성이 없는 내 문장은 기기의 음성 읽기를 사용한다. 연습 중 현재 문장과 피드백 화면의 원문을 읽고, 다른 음성과의 동시 재생을 차단하며 일시 정지·재개와 종료 시 정리를 처리한다.
- 사용자의 추가 지시에 따라 마지막 문장의 오른쪽 ‘녹음 끝내기’ 버튼을 임시로 숨겼다. 가운데 정지 버튼으로 완료하며, 중간 문장의 ‘다음 문장’ 버튼은 유지한다.
- 마이페이지 계획 바텀시트의 카드 높이, 간격, 글자, 선택 상태 및 하단 여백을 Figma에 맞췄다. 목표 아이콘과 체크는 원본 SVG를 다운로드했다. 온보딩과 선택 카드 컴포넌트를 공유한다.
- 피드백 상단의 불필요한 콘텐츠 경로 문구를 제거했다. 상세 분석 화면을 포털로 옮겨 부모 레이아웃의 여백·변형 영향을 받지 않도록 했다.
- 내 문장 녹음 화면의 하단 안전 영역을 흰색으로, 입모양 시작 화면의 상단 안전 영역을 `#f2f4f6`으로 맞췄다.
- Android에서 마이크 권한이 거부되면 앱 권한 설정으로 이동할 수 있는 버튼과 Capacitor 플러그인을 제공한다. 설정 열기에 실패하면 수동 경로를 안내한다.
- 완료 처리 회귀 테스트의 오래된 분석 API 및 projection fixture를 현재 v3 API 계약으로 갱신했다.

Figma 바텀시트 기준 노드: `1817:123`, `1817:290`, `1817:428`, `1817:561`.
녹음 화면 확인 노드: `1614:823`, `1565:581`. 마지막 완료 버튼 숨김은 사용자의 추가 지시를 따른다.

## 검증

- Android `:app:compileDebugJavaWithJavac --offline --no-daemon` 통과.
- 변경 TypeScript/TSX 파일 ESLint 오류 없음. 기존 `practice-session.tsx`의 `loadResult` effect 의존성 경고 1개는 남아 있다.

## 추가 확인

Chrome의 현재 URL을 확인할 수 없어 컴퓨터 제어가 중단되었다. 최종 화면 비교, 기기 음성 지원 여부, Android 설정 왕복 및 iOS 18.5 화면 당김 동작은 실기기 확인이 필요하다.

리포트 저장 선택은 현재 기기 내 표시 설정이며 서버의 분석 결과를 삭제하거나 여러 기기에 동기화하지 않는다. 서버 보관 정책까지 적용하려면 VC-BE의 별도 계약이 필요하다.

일부 발음 누락과 빠른 발화에 대한 분석·AI 피드백 이슈는 실제 분석 응답 확인이 필요하다. 프런트엔드에서 판정이나 점수를 만들어 넣지 않았다.

Notion의 작성된 31개 QA는 모두 **진행중**으로 반영된 상태다. 빈 행 2개는 변경하지 않았다. 최종 화면·실기기 검증 없이 완료로 표시하지 않았다.
