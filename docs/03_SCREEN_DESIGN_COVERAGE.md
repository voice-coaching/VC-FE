## API가 없는 항목

사용자 승인에 따라 내 문장 분석·억양 비교 곡선·마이 억양 요약은 고정 예시를 사용하며 예시임을 표시한다. 내 문장 녹음은 로컬에서 처리하고 예시 점수를 서버에 저장하지 않는다. 알림 시간·토글은 로컬 예시이며 실제 알림을 발송하지 않는다. 구독·공지·문의 메뉴는 명세가 없는 안내 화면이다. 계정 통계·기록·클래스 진도는 실제 API 값을 사용한다.

## 검증

- 프로덕션 빌드 통과 (신규 프로필·계획 경로 포함).
- 클래스 진행 회귀 테스트 4개 통과.
- 변경 컴포넌트 및 마이 경로 ESLint 통과.
- 브라우저에서 마이 개선안, 설정 및 계획 선택 시트 확인. 시트 변경 후 페이지 저장 없이 돌아갈 때 기존 계획 유지 확인.
- 실계정 닉네임·계획 저장, 탈퇴, 실제 마이크 녹음·서버 분석 요청은 실행하지 않았다.
- 마지막 브라우저 재확인은 `Debugger unattached` 연결 오류로 수행하지 못했다.
- 검증용 PNG와 SVG는 작업 후 삭제하며 서비스용 SVG 아바타와 폰트는 유지한다.
