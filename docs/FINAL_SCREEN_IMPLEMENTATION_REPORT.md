## 절대 위치와 고정 높이 판정

- 장식용: 로고/SVG 내부 좌표, 카메라 얼굴 가이드, 녹음 파형 막대, 원형 점수·진행 링.
- 구조 의존이지만 의도된 고정 레이아웃: 마이 상단 프로필 밴드와 402×874 기준 safe-area/상단바/하단 CTA. 모두 앱 셸 내부 값이며 화면 전체 좌표를 임의로 맞춘 해킹은 아니다.
