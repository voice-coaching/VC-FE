# 관리자 공지·기준 음성 삭제 및 알림 초안 편집

## 범위

프론트 main f124a45에서 분기한 관리자 전용 변경이다. 기존 관리자 스타일과 로그인·권한·사유 확인창을 유지한다. 일반 사용자 UI와 백엔드 코드는 변경하지 않는다.

연결 계약은 voice-coaching/VC-BE#188 및 PR #189다. 백엔드 PR의 병합·배포가 선행되어야 신규 버튼을 사용할 수 있다. 프론트 PR 작성 시 실제 운영 배포를 확인한 것으로 안내하지 않는다.

## 운영자가 사용할 위치

| 화면                                           | 추가 동작                                                  |
| ---------------------------------------------- | ---------------------------------------------------------- |
| 관리자 → 공지사항 → 공지 편집                  | 공지 삭제 → 사유 입력·확인 → 공지 목록 복귀                |
| 관리자 → 아나운서 음성 → 문장 상세 → 기준 음성 | 각 음성의 음성 삭제 → 사유 확인 → 남은 목록·대표 여부 갱신 |
| 관리자 → 알림 발송 → 작성 중 알림              | 초안 수정 → 내용·대상 변경 → 수정 저장 → 검토 후 별도 발송 |
| 관리자 → 알림 발송 → 작성 중 알림              | 초안 삭제 → 사유 확인 → 알림 목록 복귀                     |

발송 완료 알림에는 수정·삭제 동작을 표시하지 않는다. 회원에게 이미 전달한 알림의 회수 기능이 아니다. 신규 공지·알림 작성 화면에는 삭제 버튼을 표시하지 않는다.

## API 연결

- DELETE `/api/admin/notices/{noticeId}`: 현재 공지 version·reason 전송, data=null 검증 후 목록 복귀.
- DELETE `/api/admin/reference-audios/{audioId}`: 현재 음성 목록의 contentVersion·reason 전송. 반환 목록에서 삭제 음성이 제외되고 버전이 증가했는지 검증한다. 삭제 성공 후 미리듣기 중단, 콘텐츠·음성 목록·작업 이력 갱신.
- PATCH `/api/admin/notification-campaigns/{campaignId}`: version과 audience/kind/title/body/deepLink/userIds/reason 전체 전송. 편집을 열었을 때의 버전을 유지해 배경 재조회가 이전 입력을 최신 버전으로 덮어쓰지 않도록 한다.
- DELETE `/api/admin/notification-campaigns/{campaignId}`: DRAFT만 요청하며 현재 version·reason 전송, null 응답 확인 후 목록 복귀.

기준 음성 삭제는 파일 영구 삭제가 아니라 새 목록·재생 대상 제외다. 대표 음성 삭제 시 서버가 남은 음성의 대표를 지정하며 마지막 음성도 삭제할 수 있다. 새 대표·버전은 재조회한 서버 값을 사용한다. 기존 업로드 복구가 대기 중이면 삭제 버튼을 비활성화해 순서가 꼬이지 않도록 한다.

## 오류·캐시·권한

- 변경 요청을 자동 재시도하지 않는다. 처리 중 확인 버튼을 잠그고 공백 사유를 차단한다.
- 409는 입력·사유를 보존하고 상세 재확인을 안내한다. 수정 취소 후 최신 내용을 확인하고 다시 편집할 수 있다.
- 시간 초과 등 결과 미확인 오류는 성공으로 처리하거나 목록으로 이동하지 않는다. 목록·상세에서 반영 여부를 확인한 뒤 수동으로 판단한다.
- 성공 시 기존 관리자 Query 캐시 무효화를 사용한다. 공지는 notices/audit-logs, 음성은 contents/reference-audios/audit-logs, 알림은 notification-campaigns/audit-logs를 갱신한다.
- 기존 관리자 세션 분리·401/403 차단·캐시 제거를 유지한다. 이용등급 admin을 관리자 권한으로 사용하지 않는다.
- 새 작업 이력 문구는 공지 삭제·기준 음성 삭제·알림 초안 수정/삭제로 표시한다.

## 검증

서비스 계약 검증은 `npm run verify:admin`, 브라우저는 localhost 서버에서 `npm run verify:admin:browser`를 사용한다. 모의 API는 별도 브라우저 컨텍스트에서만 적용하며 운영 API에 실제 삭제·알림 발송을 요청하지 않는다. 형식 검사·타입 검사·프로덕션 빌드도 확인한다.

- 기존 API 계약90개 및 토큰 갱신 계약 검증 통과.

- 데스크톱 음성 목록과 모바일 공지 확인창·알림 초안 편집 화면을 캡처해 기존 스타일과 화면 넘침 여부를 확인했다.
- 모든 브라우저 변경 요청은 localhost 모의 API에서 처리했다. 운영 데이터 삭제·알림 발송·실제 백엔드 배포 검증은 수행하지 않았다.
