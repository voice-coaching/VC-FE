# Figma `SCREEN` 최종 디자인 반영 보고서

기준일: 2026-09-21  
기준 프레임: `03_Screen / SCREEN` 최신 비아카이브 화면  
기준 뷰포트: 402×874 CSS px

## 반영 범위

- 앱 전역을 402px 모바일 셸로 통합했다. 402px 미만은 너비가 유동적으로 줄고, 더 큰 화면에서는 앱 셸이 가운데 정렬된다.
- Figma Variables의 최종 브랜드 컬러 `#2F6BFF`와 진입 스플래시 `#336FFF`, 배경·텍스트·상태색·카드 그림자·앱 너비를 의미 기반 CSS 토큰으로 중앙화했다.
- 인증 셸도 운영 화면과 동일한 너비, `100dvh`, safe-area 규칙을 사용한다. 낮은 화면에서는 인증 콘텐츠가 스크롤된다.
- 홈의 알림, 연속 연습, 입모양 연습 진입을 실제 라우트에 연결했다.
- `/home/notifications`는 서버 계약이 없는 현재 상태를 명시적인 빈 상태로 보여 주며, 향후 데이터가 들어오면 그대로 사용할 수 있는 목록 렌더러를 포함한다.
- `/home/streak`는 통계 API와 완료 세션 API를 월 범위로 조회해 달력과 월간 완료일을 계산한다.
- `/lip-practice`는 안내, 촬영 팁, 설정, 카메라·마이크 권한, 얼굴 맞춤, 5개 문장 카운트다운/촬영/검토를 제공한다. 영상은 Object URL로 메모리에만 보관하고 업로드하지 않는다.
- 입모양 연습 이탈 시 모든 미디어 트랙과 Object URL을 해제한다. 마지막 화면은 임의 분석 결과 대신 `분석 기능 준비 중`을 표시한다.
- 서버 `ContentType`은 변경하지 않고 로컬 전용 `ExperienceKind = ContentType | "LIP_PRACTICE"`를 추가했다.
- 클래스 제목 문자열로 원리 내용을 추측하던 분기와 고정 발음·억양 SVG를 제거했다. 구조화된 원리 API가 없을 때는 준비 중 상태를 표시한다.
- 마이페이지의 고정 억양 특성 문구를 제거하고 데이터 미제공 상태를 표시한다.
- 분석 이어보기 완료 시간은 고정 1초 대신 선택된 녹음 길이를 사용한다.
- 브라우저 기본 `confirm` 대신 제품 스타일 삭제 확인 다이얼로그를 사용한다.
- 운영 라우트와 분리되어 있던 뉴스·문장·클래스·마이 및 로컬 분석 프로토타입 구현을 제거했다.

## 구조 의존 해킹 여부

구조 의존 절대 위치 해킹은 남기지 않았다. 카메라 얼굴 가이드와 오버레이, 브랜드 SVG 내부 좌표처럼 장식 자체에 필요한 위치 값만 사용한다. 고정 하단 영역은 콘텐츠 높이를 억지로 맞추지 않고 flex/sticky와 safe-area로 분리했다.

## 데이터 미제공 정책

- 알림: 빈 상태
- 입모양 자동 분석: 미지원 상태
- 클래스 구조화 원리: 준비 중 상태
- 억양 시계열/곡선: 데이터 미제공 상태
- 마이페이지 억양 특성: 데이터 미제공 상태

위 상태에는 Figma 예시 점수, 알림, 사용자 특성, 억양 곡선을 성공 데이터처럼 사용하지 않는다.
