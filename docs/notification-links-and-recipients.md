# 알림 링크와 발송 대상 선택

웹 알림함의 실제 페이지는 `/home/notifications`다. API와 관리자 입력의 기존 `/notifications` alias는 유지하되, 웹 알림 목록의 표시 경계에서 실제 페이지로 변환한다. 기존 발송 데이터 및 사용자 캐시의 href에도 같은 처리를 적용한다. `/home`, `/mypage`, 학습 기록 등 다른 내부 경로는 유지하며 외부/protocol-relative/백슬래시·제어문자 링크는 이동 링크로 만들지 않는다. 링크가 없더라도 알림과 읽음 처리는 유지한다.

관리자 알림 초안의 선택 회원 입력은 `/api/admin/users?status=ACTIVE&keyword=…&page=…&size=20` 목록에서 체크박스로 선택한다. 기본 목록을 즉시 표시하므로 회원 번호를 찾아 복사할 필요가 없다. 선택 목록은 검색·페이지 변경 및 전체/선택 대상 전환 중에도 현재 편집 화면에서 유지한다. 현재 페이지 선택/해제, 개별 선택 해제, 선택 비우기를 제공한다. 페이지 선택은 현재 조회 페이지에만 적용하며 전체 검색 결과 자동 선택을 의미하지 않는다. 최대 500명이며 서버의 최종 활성 회원 검증을 유지한다.

기존 초안의 회원 번호도 선택으로 복원한다. 현재 목록에 없는 회원은 번호로 표시하며 개별 해제할 수 있다. 선택하지 않으면 초안 저장 버튼을 비활성화하고, 전체 활성 회원 모드에서는 기존처럼 userIds=[]로 전송한다. 초안 저장/수정은 발송하지 않으며 검토 화면의 명시적인 발송 확인을 유지한다. API 필드·DB·FCM 설정 변경 및 운영 알림 재발송은 없다.

검증: 링크/선택 정책과 기존 관리자 service/cache 자동 테스트 30개, 로컬 API 대역 브라우저의 알림 링크·다중 페이지/검색 선택·조회 오류 후 재시도 3개 및 기존 관리자 회귀 34개 통과. 프로덕션 빌드와 변경 코드 ESLint 통과. 브라우저에서 읽음 처리, 모바일 너비, 검색 Enter가 초안을 제출하지 않는 동작, 정확한 선택 ID의 초안 저장과 발송 미실행을 확인했다. 운영 FCM 도착을 검증하거나 실제 회원에게 알림을 보내지 않았다.
