## 명세가 없는 데이터

사용자가 명세 없는 항목의 하드코딩을 승인했습니다.

- 홈의 주간 기록은 예시 표시를 붙인 고정 데이터입니다. 오늘 완료 횟수와 학습 시간은 기존 API를 사용합니다.
- 억양 곡선은 비교 예시이며, 실제 억양·강세·쉼 점수는 API 결과를 사용합니다.
- 내 문장은 브라우저 음성 합성과 로컬 녹음을 사용합니다. 점수와 피드백은 `design-samples.ts`의 예시이며 서버에 저장하지 않습니다.
- 클래스의 평서문·받침 ㄹ 안내는 Figma 문구와 도식을 사용합니다. 다른 클래스는 서버에서 제공하는 제목·설명·연습 본문을 사용합니다.

## 검증

- TypeScript 검사, 변경 파일 ESLint, 프로덕션 빌드.
- 클래스 결과 확인 단계 완료, 다음 원리 단계 보존, 재학습 진행률 보존, 잘못된 단계 ID 차단 회귀 테스트 4개 통과.
- 실제 로컬 브라우저에서 홈, 뉴스 경제 필터, 뉴스 상세 → 스크립트 → 녹음 준비 확인.
- 내 문장 빈 입력 비활성화, 두 문장 입력·분리·확인·미리 듣기 화면 전환 확인.
- 클래스 목록 → 상세와 서버 단계 목록·다음 단계 비활성화 표시 확인.
- 임시 검증 화면에서 분석 결과 구간 상세 열기·닫기와 속도/억양 탭 전환 및 레이아웃 확인. 임시 경로는 검증 후 삭제.
- 실제 마이크 수집 및 운영 서버의 녹음 업로드·분석 요청은 자동 검증하지 않았습니다.
