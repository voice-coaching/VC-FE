# 운영 API 엔드포인트 감사

점검일: 2026-09-29
기준: 프론트 API 어댑터 `src/lib/api/remote.ts`, 계약 검증 목록
`scripts/verify-api-contract.ts`, 운영 OpenAPI
`https://api.voice-coaching.site/v3/api-docs`

## 결론

- 프론트가 사용하는 API 경로·메서드: **80개**
- 운영 OpenAPI에 선언된 API 경로·메서드: **80개**
- 프론트 사용 API 중 운영 OpenAPI에 없는 엔드포인트: **0개**
- 운영 OpenAPI에만 있고 프론트 어댑터에 없는 엔드포인트: **0개**

현재 기준으로 프론트가 호출하지만 운영 API 계약에 없는 엔드포인트는 없다.
기존 문서에 보류로 적혀 있던 프로필 사진, 칭호·승급 시험, 단계별 예문,
예시 음성, 사용자 문장 생성, 알림과 고객 지원 API는 모두 운영 OpenAPI에
반영되어 있다.

## 운영 API가 아닌 프론트 내부 경로

아래 경로는 운영 백엔드 OpenAPI 대상이 아니며 Next.js 앱 내부에서 제공한다.

| 경로             | 상태 | 역할                                                                  |
| ---------------- | ---- | --------------------------------------------------------------------- |
| `/api/backend/*` | 존재 | 브라우저·네이티브 앱 요청을 운영 백엔드로 전달하는 동일 오리진 프록시 |
| `/api/tts`       | 존재 | 예시 음성 요청을 백엔드 MP3 응답으로 전달하는 호환 경로               |

## 감사 중 제거한 문서 전용 경로

| 경로          | 프론트 사용 | 운영 OpenAPI | 조치                                                          |
| ------------- | ----------- | ------------ | ------------------------------------------------------------- |
| `GET /health` | 사용 안 함  | 없음         | `docs/api/endpoints.md`에서 제거. 운영 계약으로 간주하지 않음 |

## 검증 범위

이번 결과는 경로와 HTTP 메서드의 정적 계약 대조다. 운영 OpenAPI에 선언되어
있다는 사실이 모든 사용자 상태와 데이터 조합에서 성공 응답을 보장하지는 않는다.
인증된 실제 요청의 응답 코드, 데이터 정합성과 스토리지·분석 서비스 상태는 별도의
통합 테스트 범위다.
